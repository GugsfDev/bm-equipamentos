# BM Equipamentos

Site demonstrativo de loja de EPI.

## Estrutura
- index.html — estrutura da página
- style.css — visual e responsividade
- script.js — produtos, categorias, carrinho e simulador de pagamento

## Como abrir
Abra o arquivo `index.html` em um navegador.

## Observação
Os produtos, preços, telefone e e-mail usados no protótipo são dados demonstrativos e devem ser substituídos pelos dados reais da BM Equipamentos antes da publicação.
